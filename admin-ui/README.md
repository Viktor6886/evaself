# Панель управления

Обычный HTML, CSS и JavaScript без сборки: `public/index.html`,
`public/ui.css` и скрипты по разделам. Caddy отдаёт каталог как есть,
поэтому правка файла — это уже деплой, а `npm run build` здесь просто
нечего делать.

Скрипты — обычные, не модули, и делят одну глобальную область; порядок
подключения задан в `index.html` и значит ровно то, чем он был, пока
всё лежало в одном файле:

* `ui-core.js` — первым: состояние, доступ к API, диалоги подтверждения,
  форматирование;
* `ui-overview.js`, `ui-services.js`, `ui-ai.js`, `ui-ai-providers.js`,
  `ui-operations.js`, `ui-users.js`, `ui-media.js`, `ui-stt.js`,
  `ui-stt-editor.js`, `ui-stt-keys.js` — по разделу на файл, вместе с их
  обработчиками;
* `ui.js` — последним: `LOADERS` перечисляет функции загрузки всех
  разделов, и до их объявления этот список собрать нельзя.

Новый раздел — новый файл рядом, строка `<script>` в `index.html` перед
`ui.js` и строка в `LOADERS`.

## Телефон — второй полноценный размер

Панель открывают с телефона не «иногда»: посмотреть, отвечает ли Ева, и
переключить провайдера — это то, что делают в дороге, а за ноутбук ради
этого не садятся.

Что из этого следует на практике:

* **Страница не имеет права прокручиваться вбок.** Это худшее, что
  может случиться на телефоне: содержимое уезжает под край экрана, и
  промахиваешься мимо всего сразу. Проверяется тестом на всех разделах.
* **Порог мобильной вёрстки — 720px**, не 680: между ними оказывались
  вкладки раздела STT, которые не помещались в строку и растягивали
  документ до 456 пикселей при экране 360.
* **Цели касания от 40 пикселей.** Палец — не мышь.
* **Поля ввода 16px.** При меньшем размере iOS и часть андроидных
  браузеров зумят страницу на фокусе и уже не отпускают.
* **Диалоги — нижние листы.** Появляются снизу, у большого пальца, с
  прокруткой внутри себя: список из шести ключей в экран не помещается.
* **У бокового меню три способа закрыться:** та же кнопка, тычок мимо
  (затемнение) и Escape. С одним только первым промах по кнопке уводит
  в другой раздел вместо закрытия.
* **Таблицы остаются таблицами** и прокручиваются внутри своей рамки:
  превращать их в карточки значит терять возможность сравнить строки,
  ради которой на них и смотрят.

Ширина проверки — 360×740: распространённый андроид (Galaxy A-серии,
Redmi). Помещается сюда — поместится и в остальные.

## Тесты

Playwright поднимает статику по http и перехватывает весь
административный API: тесты проверяют поведение интерфейса, а не
сервер, и не требуют ни базы, ни поднятых контейнеров.

```bash
cd admin-ui && npm test
```

Главное, ради чего они написаны, — отрицательные проверки, которых не
видно в коде и не поймать на сервере: какие запросы интерфейс **не**
отправляет. Ключ не уходит до подтверждения sudo, переписка не
запрашивается при открытии карточки, сохранённый секрет не показывается
обратно.

`test/mobile.test.mjs` держит отдельно то, что ломается молча: боковую
прокрутку, размеры целей касания и поведение меню.

Если Chromium в образе другой сборки, путь к нему передаётся в
`EVA_CHROMIUM_PATH` — иначе Playwright ищет ровно ту сборку, под
которую собран, и не находит.
