# Как ставить задачу агенту

1. Прочитать `CLAUDE.md`, `PROGRESS.md`, `docs/letta-native.md` и только документацию затрагиваемой подсистемы.
2. Выполнять только задачу, явно поставленную человеком. Старый roadmap и архивные prompts не являются очередью работ.
3. До изменений сверить задачу с фактическим `main` и границей Letta-native.
4. Переиспользовать существующие компоненты из `docs/IMPLEMENTATION_STATE.md`; не создавать параллельный когнитивный runtime.
5. Проверить затронутую область, тесты, безопасность, миграции и rollback в объёме поставленной задачи.

## Обязательная граница

Letta Agent SDK и App Server отвечают за агента, conversations, историю, контекст, память, skills, recall, Dreaming и выбор инструментов. Evaself отвечает за продуктовые данные, tenancy, Telegram, Mini App, доставку, задания, платежи, безопасность и наблюдаемость.

Нельзя восстанавливать удалённый когнитивный middleware или переносить управление памятью, контекстом и выбором skills из Letta в Evaself.
