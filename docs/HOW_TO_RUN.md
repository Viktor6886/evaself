# Как запускать доработку Evaself

Инструкция для человека. Работает с любого устройства, включая телефон.

## Что где лежит

| Файл | Что это |
|---|---|
| `CLAUDE.md` | Правила проекта. Агент читает его автоматически в каждой сессии. |
| `PROGRESS.md` | Журнал: что уже сделано, что следующее. Единственный источник истины о прогрессе. |
| `prompts/step-00…step-33` | 34 задания. Агент берёт их сам, копировать вручную не нужно. |
| `docs/*.docx` | Полные документы: техническое задание и промпт с анализом. |

## Как запустить очередной шаг

Откройте **claude.ai/code**, выберите репозиторий `Viktor6886/evaself`, создайте
новую сессию и напишите одну фразу:

```
Прочитай CLAUDE.md и PROGRESS.md. Определи следующий невыполненный шаг,
прочитай его файл в prompts/ и расскажи, что собираешься делать. Не начинай
без моего разрешения.
```

Агент ответит: какой шаг, что будет сделано, какие файлы затронет.

Если согласны — напишите `да, выполняй`. Если нет — `пропусти этот шаг` или
`сначала объясни подробнее`.

После выполнения агент обновит `PROGRESS.md`, откроет pull request и остановится.
Следующий шаг он без вашего разрешения не начнёт.

## Как принять работу

1. Откройте вкладку **Pull requests** в репозитории на GitHub.
2. Откройте свежий pull request, посмотрите вкладку **Files changed**.
3. Если всё устраивает — **Merge pull request** → **Confirm merge**.

Шаг считается завершённым только после мержа.

### На что смотреть в отчёте агента

- Есть ли реальный вывод команд сборки и тестов. Если написано просто
  «тесты прошли» без вывода — попросите вставить фактический вывод.
- Заключение: `шаг завершён` или `шаг заблокирован`. Второе — нормально,
  так задумано. Не заставляйте продолжать, разберитесь с причиной.
- Размер изменений. Если pull request подозрительно большой, агент вышел за
  границы шага: в каждом файле шага есть раздел «НЕ ДЕЛАЙ В ЭТОМ ШАГЕ».

## Передача работы другому агенту

`PROGRESS.md` и `CLAUDE.md` написаны так, что их понимает любой агент, а не
только Claude Code. Чтобы продолжить работу, например, в Codex, дайте ту же
фразу, что и выше. Агент прочитает журнал и продолжит с последнего невыполненного
шага.

Именно поэтому запрещено вести прогресс где-либо ещё: в переписке, в заметках
или в голове. Всё, что нужно следующему агенту, должно быть в `PROGRESS.md`.

## Важно

- **Один шаг за раз.** Не запускайте две сессии параллельно — они трогают одни
  файлы, конфликты гарантированы.
- **Мерж не включает функцию.** Все новые подсистемы приходят выключенными
  через feature flag. Включать их нужно отдельно на сервере, по инструкции из
  раздела ROLLOUT соответствующего шага. Так откат остаётся мгновенным.
- **Если сессия оборвалась на середине шага** — откройте новую и напишите:
  `Ветка claude/step-NN-… уже существует, продолжи с текущего состояния.`
- **Если шаг слишком большой** (в шапке написано «2–3 PR») — можно попросить:
  `Сделай только пункты 1–5, остальное отдельным pull request.`
