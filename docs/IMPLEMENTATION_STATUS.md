# Статус реализации интерфейсов

Evaself использует `@letta-ai/letta-agent-sdk` 0.5.5 как единственный
программный интерфейс к Letta App Server. Матрица ниже фиксирует реальные
возможности этой версии и не обещает операции, которых нет в SDK.

| Возможность | Статус |
|---|---|
| Список, поиск, фильтрация, создание, изменение и удаление agents | Реализовано |
| Расширенное создание: system prompt, memory, tools, skills, dreaming, embedding, models | Реализовано |
| Conversations, история, архивирование | Реализовано |
| Стриминговый чат, остановка хода, повтор запроса | Реализовано |
| Reasoning/tool events/raw trace | Показывается, когда SDK возвращает эти данные; секреты удаляются |
| Настройки runtime SDK, permissions и reasoning effort | Реализовано |
| Массовое изменение поддерживаемых полей | Реализовано с preview и автоматическим rollback |
| JSON экспорт/импорт agents | Реализовано |
| Журнал административных действий | Реализовано |
| CRUD LLM-провайдеров, проверка `/models`, безопасное переключение | Реализовано |
| CRUD существующих memory blocks | Read-only: management-методов нет в SDK 0.5.5 |
| CRUD custom tools и Tool Rules | Read-only: management-методов нет в SDK 0.5.5 |
| MCP servers, skills и knowledge folders | Read-only: management-методов нет в SDK 0.5.5 |
| Identities, managed groups, compaction существующего agent | Не поддержано текущим SDK |
| Экспорт YAML/ZIP/`.af` | Не поддержано текущим SDK |
| Общая конфигурация инфраструктуры из браузера | Системные параметры, Secret Store, статусы, проверки и перезапуск реализованы |
| Обзор без внешних запросов и фоновые health-снимки | Реализовано отдельным `health-worker` |
| Перезапуск контейнеров из WebUI | Реализовано через ограниченный `eva-updater`; admin-api без Docker socket |
| Backup и проверка обновлений из WebUI | Реализовано как асинхронные операции |
| Зашифрованный backup и legacy restore | Реализовано; мастер-ключ хранится отдельно |
| SSRF-защита административных Base URL | Реализовано через `OutboundGateway` |
| Mini App: «Сегодня», «Цели», «Прогресс», «Профиль» | Реализовано, Telegram HMAC auth |
| Создание/пауза цели, старт/завершение рабочего блока | Реализовано |
| Автосохранение и подтверждение полей профиля | Реализовано |
| Полное зеркало переписки в PostgreSQL | Отключено; история остаётся в Letta |

Ограниченные функции не имитируются прямыми HTTP-запросами к Letta. После
добавления официальных management-методов их можно включить, не меняя
архитектурную границу проекта.
