# Установка

## До начала

Подготовьте Ubuntu 24.04 x86_64 и, при публичной установке, корневой домен.
Установщик автоматически создаст адреса `app` и `api`. Больше публичных
имён не требуется: административная панель, Letta и мониторинг живут на
корневом домене под `/admin`. Telegram bot token, ID владельца и
OpenAI-compatible LLM можно пропустить и настроить позже.

Порты 80/tcp, 443/tcp и 443/udp должны быть доступны из интернета. SSH-порт
не меняется установщиком.

## Запуск

```bash
git clone https://github.com/Viktor6886/evaself.git
cd evaself
sudo make install
```

Обычный мастер запрашивает минимум данных. Введите `skip` или нажмите Enter,
чтобы пропустить необязательное поле. Расширенный режим с ручными
поддоменами, параметрами LLM и embeddings запускается командой:

```bash
make configure-advanced
```

Дополнительные параметры LLM уже имеют корректный JSON по умолчанию и не
требуют ручного ввода. Часовой пояс выбирается из списка с поиском, если
терминал интерактивный. Остальные пароли и токены генерируются один раз.
`.env` получает mode 600 и исключён из Git.

После запуска установщик:

1. устанавливает Docker, firewall и Fail2Ban;
2. создаёт конфигурацию и собирает образы;
3. запускает PostgreSQL/Valkey и остальные сервисы;
4. применяет миграции;
5. при наличии данных создаёт, проверяет и активирует первую
   LLM-конфигурацию;
6. при наличии токена регистрирует прямой Telegram webhook TypeScript
   runtime;
7. устанавливает systemd timer ежедневного backup;
8. запускает `make doctor`.

Если необязательные значения пропущены, установка завершается в режиме
неполной конфигурации и выводит их список. Если заданный провайдер не
проходит проверку, нерабочая конфигурация не помечается активной.

## После установки

```bash
make doctor
scripts/telegram-webhook.sh set
make configure-llm       # дополнительные провайдеры
make list-models
```

После регистрации webhook бот готов принимать сообщения.

Административная панель открывается по адресу
`https://<корневой-домен>/admin`. Это единственный административный вход
установки: server-side сессия, CSRF-защита, роли, sudo-режим, системные
настройки, write-only Secret Store и аудит. Первый `owner` создаётся из
`EVA_ADMIN_USERNAME`; bootstrap-пароль после успешного импорта
автоматически удаляется из `.env`.

Агенты, conversations, настройки SDK, реестр LLM и мониторинг — разделы
этой же панели: `/admin/agents`, `/admin/letta`, `/admin/monitoring`.
Отдельных поддоменов и второго Basic Auth больше нет. Capability token
App Server и значения секретов браузеру не передаются.

Установка, обновлённая с прежней раскладки, продолжает отвечать на
`letta.<домен>` и `status.<домен>` — но только 308-редиректом на нужный
раздел. Когда закладки обновлены, очистите `DOMAIN_LETTA` и
`DOMAIN_STATUS` в `.env`, выполните `make restart` и удалите две
A-записи: имена перестанут публиковаться, и сертификаты для них
запрашиваться не будут.

Пользовательский Telegram Mini App доступен на `/app/`. Укажите полный URL
в BotFather для кнопки меню бота. Mini App открывается только с валидным
Telegram `initData`; открытие ссылки в обычном браузере намеренно не даёт
доступ к данным.

Инфраструктурные значения, которые требуют перезапуска контейнеров,
дозаполняются без переустановки:

```bash
make configure
docker compose up -d
```

## Повторный запуск

`sudo make install` можно выполнить повторно: существующие секреты,
PostgreSQL, volumes, agents, conversations и LLM-конфигурации сохраняются.
Повторный импорт `.env` пропускается, если реестр LLM уже заполнен.
Полный лог установки находится в `/var/log/evaself-install.log`.

Migrations применяются установщиком идемпотентно. Они создают durable
inbox/outbox, локаль и timezone, профиль, цели и служебные conversation
purposes. Память, история и управление контекстом остаются в Letta.

## Диагностика

```bash
make status
make doctor
make logs s=eva-agent-service
make logs s=letta-app-server
make test-llm
```

## Удаление

`make stop` останавливает сервисы и сохраняет данные. Удаление volumes
намеренно выполняется только вручную. Перед ним обязательно сделайте
`make backup`: отменить удаление volumes невозможно.
