# Архив прежнего roadmap

Старый roadmap отменён после перехода на Letta-native архитектуру. Он предполагал параллельные механизмы управления памятью, контекстом, skills и инструментами, дублировавшие Letta Agent SDK и App Server.

Архив не является очередью работ и не должен выполняться или восстанавливаться. Новая работа начинается только с явно поставленной человеком задачи и проверяется по:

- `CLAUDE.md`;
- `PROGRESS.md`;
- [letta-native.md](letta-native.md);
- [ARCHITECTURE.md](ARCHITECTURE.md);
- фактическому `main`.

Исторические названия удалённых подсистем могут встречаться здесь только как объяснение причины отмены: Memory Curator, SkillRouter, ToolGateway, Hybrid Retrieval, Deep Recall, graph memory и temporal memory.
