# NocoDB

Графический административный просмотр данных Евы. PostgreSQL остаётся
источником истины.

NocoDB использует отдельную базу `nocodb` для своих метаданных, а `eva`
автоматически подключается как внешний источник PostgreSQL во время
`make install`. Все существующие таблицы и поддерживаемые представления
появляются в базе `Evaself`; повторная команда синхронизирует новые миграции:

```bash
make nocodb-sync
```

Структура таблиц доступна только для чтения, поэтому NocoDB не может изменить
схему. Данные можно редактировать из интерфейса. Пароль PostgreSQL передаётся
только внутри Docker-сети и не выводится в терминал.

Основные представления: `v_user_overview`, `v_agent_runtime`,
`v_quota_status`, `v_revenue_monthly`, `v_crisis_open`. LLM-конфигурации
редактируйте только через Letta UI/API, а не напрямую в NocoDB: активация
требует проверки, App Server restart и SDK update.
