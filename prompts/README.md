# Шаги доработки Evaself

Каталог содержит 34 шага доработки проекта. Каждый файл — самодостаточное
задание для агента: его можно выполнить, не читая остальные шаги.

## Для агента

1. Прочитай `CLAUDE.md` в корне — там инварианты, бюджеты, запреты и протокол работы.
2. Прочитай `PROGRESS.md` в корне — там видно, какой шаг следующий.
3. Прочитай файл следующего шага целиком.
4. Сообщи человеку, что собираешься делать, и **дождись явного разрешения**.
5. Выполни ровно один шаг, обнови `PROGRESS.md`, открой pull request, остановись.

## Порядок

Шаги идут строго по возрастанию номера. Внутри блока приоритета порядок можно
менять только при отсутствии зависимости, указанной в шапке шага.

| Блок | Шаги | Смысл | Можно остановиться после блока |
|---|---|---|---|
| P0 | 00–04 | Безопасность, изоляция арендаторов, жизненный цикл хода, параллелизм | да |
| P1 | 05–13 | Рабочая версия: восстановление, очереди, наблюдаемость, retention, обновление SDK, административный CRUD, версии | да |
| P2 | 14–22 | Качество ответа: инструменты, память, навыки, субагенты, evals | да |
| P3 | 23–30 | Продукт и масштаб: знания, исследования, интерфейсы, аналитика, backup, нагрузка, приёмка | да |
| P4 | 31–33 | Опционально: шардирование, расширения, dreaming — только при доказанной необходимости | — |

Блок P4 не нужен для цели «500 одновременно активных пользователей».

## Полные документы

- `docs/evaself-consolidated-ts-v1.0.docx` — консолидированное техническое задание: аудит текущей реализации, архитектурные решения, модель данных, этапы.
- `docs/evaself-claude-code-prompt-v2.0.docx` — эти же шаги в виде документа с анализом исходного промпта.
- `docs/HOW_TO_RUN.md` — инструкция для человека, как запускать шаги.
