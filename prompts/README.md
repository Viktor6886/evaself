# Шаги доработки Evaself

Каталог содержит 68 шагов доработки проекта: 00–33 — первый слой, 34–67 — второй. Каждый файл — самодостаточное
задание для агента: его можно выполнить, не читая остальные шаги.

## Команда для запуска

Одна и та же на каждой порции, для любого агента:

```
Работай в репозитории Viktor6886/evaself.

Сначала перейди в корень репозитория — это каталог, в котором лежат файлы
CLAUDE.md, PROGRESS.md и каталог prompts/. Если ты сейчас не в нём, найди
корень командой git rev-parse --show-toplevel и перейди туда. Если репозиторий
не склонирован — склонируй его. Все пути ниже указаны относительно корня.

Дальше:
1. Прочитай CLAUDE.md и PROGRESS.md полностью.
2. Найди в PROGRESS.md первый шаг со статусом «не начат» и определи его порцию.
   Границы порций — строки с отметкой ⏸.
3. Назови мне номер порции, входящие в неё шаги и что собираешься сделать.
4. Выполни всю порцию по протоколу из раздела «Протокол выполнения шагов»
   в CLAUDE.md: задание из prompts/, проверки, обновление PROGRESS.md,
   pull request, независимая проверка, мерж по условиям, следующий шаг порции.
5. На отметке ⏸ остановись, выведи сводку по шагам порции и спроси
   разрешения на следующую порцию.

Ничего не делай сверх порции. При провале любой проверки не мержи: поставь
статус «заблокирован», объясни причину и остановись.
```

## Для агента

1. Прочитай `CLAUDE.md` в корне — там инварианты, бюджеты, запреты и протокол работы.
2. Прочитай `PROGRESS.md` в корне — там видно, какой шаг следующий и в какую порцию он входит.
3. Работай порцией: выполнил шаг → проверки → журнал → pull request →
   мерж по условиям протокола → следующий шаг порции. Порция — 1–3 шага
   между отметками ⏸ в `PROGRESS.md`.
4. На отметке ⏸ остановись, выведи сводку и спроси разрешения на следующую порцию.
5. При любом провале проверок — не мержи, поставь статус `заблокирован`, доложи и остановись.

## Порядок

Шаги идут строго по возрастанию номера. Внутри порции порядок можно
менять только при отсутствии зависимости, указанной в шапке шага.

| Блок | Шаги | Смысл |
|---|---|---|
| P0 | 00–04 | Безопасность, изоляция арендаторов, жизненный цикл хода, параллелизм |
| P1 | 05–13 | Рабочая версия: восстановление, очереди, наблюдаемость, retention, обновление SDK, административный CRUD, версии |
| P2 | 14–22 | Качество ответа: инструменты, память, навыки, субагенты, evals |
| P3 | 23–30 | Продукт и масштаб: знания, исследования, интерфейсы, аналитика, backup, нагрузка, приёмка |
| P4 | 31–33 | Опционально: шардирование, расширения, dreaming — только по отдельной команде |
| P5 | 34–37 | Ledger потребления, квоты и гранты, платёжный слой, жизненный цикл подписки |
| P6 | 38–40 | Кнопки, опросы, контакты, файлы, персона и режимы тона |
| P7 | 41–44 | Речь, документы и изображения, генерация файлов, встречи |
| P8 | 45–48 | Лицензионный шлюз методик, PsychometricsEngine, импорт, экраны тестов |
| P9 | 49–54 | Интервью, формулировка 5P, «Моя жизнь», сигналы |
| P10 | 55–58 | Практики, антистресс, живой портрет, прозрачная память |
| P11 | 59–60 | Контакты, приглашения, совместимость, рефералы |
| P12 | 61–63 | Раздел «Пользователи», админка второго слоя, лендинг |
| P13 | 64–65 | Кризисный контур, итоговая интеграция второго слоя |
| P14 | 66–67 | Опционально: распорядок и питание, астрорефлексия |

Блоки P5–P13 начинаются после шага 30. Полное описание второго слоя, снятые
противоречия источников и модель данных — в `docs/EVASELF_LAYER2_PLAN.md`.

Одна команда человека = одна порция (1–3 шага, в блоке P9 — до шести).
Всего 33 порции на 68 шагов.
Границы порций заданы отметками ⏸ в `PROGRESS.md` и менять их нельзя.

Блок P4 не нужен для цели «500 одновременно активных пользователей».

## Полные документы

- `docs/evaself-consolidated-ts-v1.0.docx` — консолидированное техническое задание: аудит текущей реализации, архитектурные решения, модель данных, этапы.
- `docs/evaself-claude-code-prompt-v2.0.docx` — эти же шаги в виде документа с анализом исходного промпта.
- `docs/EVASELF_LAYER2_PLAN.md` — план второго слоя: что исключено как дубликат, снятые противоречия, модель данных, критерии приёмки.
- `docs/HOW_TO_RUN.md` — инструкция для человека, как запускать шаги.
