# Шаг 21. Ограниченные субагенты и фоновая рефлексия

- **Приоритет:** P2
- **Зависит от:** шаги 8, 16
- **Feature flag:** EVA_SUBAGENTS, EVA_REFLECTION_SUBAGENT
- **Размер:** M

> Протокол — `CLAUDE.md`. Шаг выполняется внутри batch: pull request, CI и ревью — на batch, не на шаг.

---

ЦЕЛЬ:
Выполнять рефлексию и другую фоновую когнитивную работу изолированным субагентом с жёсткими лимитами, не расширяя права основного агента.

СНАЧАЛА ПРОВЕРЬ:
Механизм agent jobs из шага 8 и конвейер кандидатов из шага 16. Субагент строится на них, третий механизм не создаётся.

СДЕЛАЙ:
1. Создай декларативный реестр разрешённых субагентов. Разрешены только: рефлексия памяти, диагностика памяти, поиск по истории, поиск по базе знаний, анализ документа, обзор целей, проверка безопасности. Основной агент не может создать произвольного субагента по текстовому запросу.
2. Определение субагента задаёт: политику модели, ссылку на системный промпт, разрешённые инструменты, разрешённые навыки, разрешённые области памяти, режим выполнения, режим доступа (только чтение либо запись кандидатов), максимум входных и выходных токенов, таймаут, максимальную стоимость, число повторов и схему результата.
3. Субагенту запрещено передавать: весь профиль пользователя, все блоки памяти, чужие conversations, секреты, неограниченный набор инструментов, полный журнал инструментов основного агента и полную историю разговора.
4. Основной агент получает только статус, структурированный результат, ссылки на доказательства, предупреждения и метаданные стоимости. Полная внутренняя трасса субагента в контекст не попадает.
5. Рефлексия запускается по завершении смыслового эпизода или после 8–15 содержательных сообщений, через очередь, с режимом дедупликации keep-last-if-active.
6. Рефлексия анализирует только ограниченный диапазон сообщений, отличает факт от предположения, не ставит диагнозов, сохраняет доказательства, учитывает режим приватности и не перезаписывает конфликтующий факт без новой версии.
7. Рекурсивные и неограниченные субагенты запрещены: субагент не может запускать субагента.
8. Субагенты не вызываются для простых сообщений.

НЕ ДЕЛАЙ В ЭТОМ ШАГЕ:
Не давай субагенту право записи в каноническую память. Не создавай второго постоянного агента. Не реализуй dreaming.

ТЕСТЫ:
Субагент не выходит за лимиты токенов, времени и стоимости; попытка вызвать неразрешённый инструмент отклоняется; попытка обратиться к чужим данным отклоняется; результат всегда соответствует схеме; параллельные задания одного пользователя не запускаются; рекурсия невозможна; отказ субагента не ломает основной ход.

ГОТОВО, КОГДА:
Рефлексия работает в фоне, все лимиты соблюдаются и измеряются, основной ход от неё не зависит.

ОТЧЁТ:
По формату из CLAUDE.md. Приложи фактические расходы токенов и стоимости на одну рефлексию.
