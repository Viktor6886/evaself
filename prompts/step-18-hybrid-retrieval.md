ЦЕЛЬ:
Сделать так, чтобы Runtime Context работал на актуальных данных, но умел обращаться к истории, а в модель попадал только компактный релевантный подграф.

СНАЧАЛА ПРОВЕРЬ:
Текущий сборщик runtime context, текущий графовый сервис и его ограничения, установлено ли расширение pgvector и используется ли оно фактически.

СДЕЛАЙ:
1. Добавь embeddings для кратких описаний узлов, канонических представлений фактов и содержания эпизодов. Храни модель, размерность и версию embedding. Смена модели выполняется фоновой переиндексацией, а не единовременной перезаписью.
2. Реализуй гибридный поиск: полнотекстовый поиск, триграммы, векторное сходство и расширение по графу с последующим объединением и ранжированием. Второй поисковый контур не создаётся.
3. Фильтр по пользователю применяется до полнотекстового и векторного поиска и до обхода графа.
4. Ограничь обход графа: глубина по умолчанию 1, максимум 3, ограничение по числу узлов и связей, жёсткий таймаут запроса.
5. Раздели runtime context на уровни с отдельными бюджетами: постоянная часть, активные навыки, персональная память, знания, текущий разговор. Фиксируй фактический размер каждого уровня.
6. Реализуй Deep Recall как отдельный инструмент, вызываемый только при необходимости: явный вопрос о прошлом, обнаруженная ссылка на время, недостаток контекста. Он имеет собственный бюджет и не вызывается на каждом ходу.
7. Retrieval учитывает пользователя, приватность, уверенность, релевантность и время. Поддержи запрос состояния на дату.
8. Полная стенограмма разговора в промпт не передаётся ни при каких условиях.

НЕ ДЕЛАЙ В ЭТОМ ШАГЕ:
Не подключай внешние векторные базы. Не создавай таблицы, принадлежащие LangChain. Не расширяй набор memory blocks.

ТЕСТЫ:
Нулевая утечка кандидатов между пользователями в векторном поиске; корректность запросов «сейчас» и «на дату»; дубликаты фрагментов удаляются; бюджеты уровней соблюдаются и измеряются; таймаут поиска приводит к безопасной деградации, а не к ошибке ответа; Deep Recall не вызывается на обычном сообщении.

ГОТОВО, КОГДА:
Поиск гибридный и изолированный, размеры уровней контекста измеряются, Deep Recall вызывается только по необходимости.

ОТЧЁТ:
По формату из CLAUDE.md. Приложи измеренные размеры уровней контекста на реальном ходе.
