# Шаг 23. Безопасная загрузка документов и граница базы знаний на LangChain

- **Приоритет:** P3
- **Зависит от:** шаги 7, 18
- **Feature flag:** EVA_LANGCHAIN
- **Объём:** 1–2 PR
- **Ветка:** `step/23-langchain-knowledge`

> Перед началом прочитай `CLAUDE.md` — там протокол автономной работы.
> Выполни только этот шаг: проверки, `PROGRESS.md`, pull request, мерж по условиям
> из протокола. Затем возьми следующий шаг блока. На границе блока остановись.

---

Прочитай CLAUDE.md и следуй его инвариантам.

ЦЕЛЬ:
Использовать LangChain только как библиотеку обработки данных, не создавая второй runtime и второе хранилище.

СДЕЛАЙ:
1. Разрешено: загрузчики документов, нормализация, разбиение на фрагменты, адаптеры embeddings, интерфейсы retriever, реранкинг, сжатие контекста и структурированный вывод.
2. Запрещено: агент, память, контрольные точки, сценарии, планировщик, Telegram-runtime и шлюз безопасности на базе LangChain или LangGraph.
3. Все обращения к моделям идут через существующий LLM Router.
4. Загрузка выполняется в фоновой очереди: проверка типа, размера и числа страниц, антивирусная проверка, изолированное временное хранилище, извлечение текста, нормализация, проверка на внедрение инструкций, разбиение на фрагменты, embeddings, очистка временных файлов.
5. Персональная память и база знаний разделены и не смешиваются: база знаний содержит проверенные материалы продукта, память — сведения о пользователе.
6. Содержимое документа считается недоверенным и не может изменять права, инструменты и системные инструкции.
7. Структурированный вывод обязателен для Curator, Doctor, reranker маршрутизатора, инсайтов и отчётов исследования. Ошибка схемы приводит к контролируемому повтору с деградацией, а не к возврату сырого текста.

НЕ ДЕЛАЙ В ЭТОМ ШАГЕ:
Не создавай таблицы, принадлежащие LangChain. Не подключай внешнюю векторную базу. Не смешивай знания и память.

ТЕСТЫ:
Вредоносный документ с внедрённой инструкцией не меняет поведение агента; превышение размера и неподдерживаемый тип отклоняются; временные файлы удаляются; фрагменты изолированы по пользователю там, где документ пользовательский; ошибка схемы обрабатывается контролируемо.

ГОТОВО, КОГДА:
Документы обрабатываются безопасно, база знаний отделена от памяти, второй runtime не появился.

ОТЧЁТ:
По формату из CLAUDE.md.
