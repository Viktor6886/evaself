# Шаг 42. Конвейер файлов, изображений и внешних источников

- **Приоритет:** P7
- **Зависит от:** шаги 23, 39, 41
- **Feature flag:** EVA_FILE_PIPELINE
- **Объём:** 2 PR
- **Ветка:** `step/42-file-pipeline`

> Перед началом прочитай `CLAUDE.md` — там протокол автономной работы.
> Выполни только этот шаг: проверки, `PROGRESS.md`, pull request, мерж по условиям
> из протокола. Затем возьми следующий шаг порции. На отметке ⏸ остановись.

---

**ЦЕЛЬ.** Безопасно принимать документы и изображения и подключать их к базе знаний пользователя.

**СНАЧАЛА ПРОВЕРЬ.** Что уже сделал шаг 23: загрузчики, нормализация, чанкинг, embeddings, изоляция по пользователю. Здесь добавляются только новые типы и распознавание изображений.

**СДЕЛАЙ.**
1. Поддержи `docx`, `pdf`, `txt`, `md`, изображения и поддерживаемые аудиоформаты. Проверяй MIME, расширение, размер и сигнатуру файла.
2. Несколько вложений обрабатываются очередью, а не одновременно в ходе ответа.
3. Добавь распознавание изображений: описание, OCR при необходимости, извлечение структурированных данных, связь с текущей задачей пользователя. Распознавание лиц для скрытой идентификации запрещено. Чувствительный вывод требует подтверждения пользователя.
4. Результаты подключаются к базе знаний пользователя из шага 23. Второе хранилище не создаётся. Удаление документа удаляет его из индекса и embeddings.
5. Добавь YouTube как источник внутри Research Orchestrator из шага 24: получение транскрипта, краткое содержание, тезисы, связь с задачей, корректная обработка отсутствия транскрипта и ограничений доступа.
6. Временные ссылки для просмотра администратором подписываются и имеют короткий срок.

**НЕ ДЕЛАЙ В ЭТОМ ШАГЕ.** Не создавай второй RAG. Не реализуй генерацию файлов — шаг 43.

**ТЕСТЫ.** Неподдерживаемый тип и превышение размера отклоняются; документ с внедрённой инструкцией не меняет поведение агента; удаление документа очищает индекс; чужой файл недоступен; расход изображений и анализа попадает в ledger.

**ГОТОВО, КОГДА.** Пользователь может прислать документ, фото или ссылку и обсуждать содержимое, не смешивая свои данные с чужими.
