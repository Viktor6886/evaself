# Шаг 44. Транскрипция и анализ встреч

- **Приоритет:** P7
- **Зависит от:** шаги 41, 42
- **Feature flag:** EVA_MEETINGS
- **Объём:** 2 PR
- **Ветка:** `step/44-meetings`

> Перед началом прочитай `CLAUDE.md` — там протокол автономной работы.
> Выполни только этот шаг: проверки, `PROGRESS.md`, pull request, мерж по условиям
> из протокола. Затем возьми следующий шаг порции. На отметке ⏸ остановись.

---

**ЦЕЛЬ.** Превращать запись встречи в подтверждённые договорённости и задачи.

**СДЕЛАЙ.**
1. Источники: аудио, видео, Telegram voice и document, запись в WebApp после явного запуска, готовая транскрипция.
2. Конвейер: файл → проверка → приватное хранение → ASR → диаризация → сегменты с временными метками → предпросмотр → подтверждение → анализ. Выполняется заданиями существующей очереди `media-processing`.
3. Создай `meeting_records`, `meeting_media`, `meeting_transcripts`, `meeting_transcript_segments`, `meeting_insights`, `meeting_action_candidates`.
4. Результат: краткое резюме, темы, решения, договорённости, задачи, ответственные, сроки, открытые вопросы, риски и подтверждающие цитаты со ссылкой на временную метку.
5. Задачи не создаются без подтверждения пользователя.
6. Перед записью показывай обязанность получить согласие участников и соблюдать местное законодательство. Сырые медиа удаляются по политике хранения из шага 10. Встречи не используются для обучения моделей.

**НЕ ДЕЛАЙ В ЭТОМ ШАГЕ.** Не включай запись без явного действия пользователя. Не создавай задачи автоматически.

**ТЕСТЫ.** Длинная транскрипция не блокирует очередь; сегменты сопоставлены с временными метками; кандидаты в задачи не создают задачи без подтверждения; сырое медиа удаляется по сроку; чужая встреча недоступна.

**ГОТОВО, КОГДА.** Из записи получается проверяемый список договорённостей со ссылками на моменты записи.
