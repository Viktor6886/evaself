# Шаг 45. Лицензионный шлюз методик

- **Приоритет:** P8
- **Зависит от:** шаги 12, 13
- **Feature flag:** EVA_PSYCHOMETRICS
- **Объём:** 1 PR
- **Ветка:** `step/45-instrument-rights`

> Перед началом прочитай `CLAUDE.md` — там протокол автономной работы.
> Выполни только этот шаг: проверки, `PROGRESS.md`, pull request, мерж по условиям
> из протокола. Затем возьми следующий шаг порции. На отметке ⏸ остановись.

---

**ЦЕЛЬ.** Сделать технически невозможной публикацию методики без права на коммерческое электронное использование.

**СДЕЛАЙ.**
1. Создай `psych_instruments`, `psych_instrument_versions`, `psych_instrument_rights`.
2. Статусы прав: `approved`, `noncommercial_only`, `permission_required`, `translation_validation_required`, `disabled_pending_rights`.
3. Запись о правах содержит правообладателя, исходный URL, код лицензии, признаки допустимости коммерческого и электронного использования, перевода и производных, текст атрибуции, ссылку на хранимое подтверждение, дату и автора проверки.
4. Production API не выдаёт вопросы, если коммерческое использование не разрешено. Feature flag этот запрет не обходит — проверка выполняется в сервисе, а не во флаге.
5. Admin UI показывает причину блокировки и позволяет приложить подтверждение.
6. Для разработки допустим отдельный режим исследования с заметной маркировкой; он не включается в production.
7. Стартовые статусы: BFI-10 и русская версия GESIS — `noncommercial_only`; OEJTS 1.2 — `noncommercial_only`; PVQ-21 — `noncommercial_only`; O*NET Mini-IP — `approved` только после выбора и сохранения допустимой лицензии и атрибуции; BEIS-10 — `permission_required`; ECR-RS и русская адаптация — `permission_required`.
8. Дополнительный набор скрининговых шкал регистрируется в реестре со статусом `disabled_pending_rights` и в production не включается.

**НЕ ДЕЛАЙ В ЭТОМ ШАГЕ.** Не импортируй тексты вопросов. Не реализуй scoring.

**ТЕСТЫ.** Запрос вопросов заблокированной методики отклоняется; включение флага не открывает доступ; смена статуса фиксируется в аудите; отсутствие подтверждения не позволяет перевести в `approved`.

**ГОТОВО, КОГДА.** Ни одна методика не может попасть к пользователю в обход проверки прав.
