# Шаг 47. Импорт item banks обязательных методик

- **Приоритет:** P8
- **Зависит от:** шаг 46
- **Feature flag:** EVA_PSYCHOMETRICS
- **Объём:** 2 PR
- **Ветка:** `step/47-instrument-import`

> Перед началом прочитай `CLAUDE.md` — там протокол автономной работы.
> Выполни только этот шаг: проверки, `PROGRESS.md`, pull request, мерж по условиям
> из протокола. Затем возьми следующий шаг порции. На отметке ⏸ остановись.

---

**ЦЕЛЬ.** Загрузить тексты только тех версий, на которые получено право, и проверить ключи контрольными тестами.

**СДЕЛАЙ.**
1. Создай структуру `psychometrics/` с каталогами манифестов, лицензированных пунктов, схем, scoring и импортёром. Каталог лицензированных пунктов не коммитится без подтверждённого разрешения.
2. Каждый манифест содержит источник, контрольную сумму, порядок, ключ подсчёта, статус прав и ожидаемое число вопросов. Импорт завершается ошибкой при несовпадении числа или порядка.
3. Реализуй манифесты и ключи для: BFI-10 английская версия; BFI-10rus GESIS/ISSP; OEJTS 1.2; O*NET Mini Interest Profiler 30; BEIS-10; PVQ-21; ECR-RS.
4. Порядок пунктов русской версии BFI-10 отличается от английской — подменять перевод английской формы запрещено, ключи хранятся раздельно.
5. Для OEJTS хранить обе стороны биполярной пары отдельно, непрерывные значения, расстояние от порога и устойчивость; при близости к середине сообщать, что предпочтение выражено слабо.
6. Для O*NET показывать все шесть значений, топ-3 с сохранением равенств, описания рабочих сред и ограничение «интерес не равен способности».
7. Для PVQ-21 основной отчёт строить по центрированным значениям, не называть ценность хорошей или плохой, не сравнивать со странами без проверки инвариантности.
8. Для ECR-RS результат — две непрерывные шкалы по каждой выбранной фигуре; категории привязанности допустимы только как упрощённая образовательная визуализация; глобальный показатель считается только по явно выбранным фигурам с перечислением вошедших блоков.
9. Переписывать защищённый вопрос «похожей формулировкой» запрещено: это другая, невалидированная методика.
10. Сохрани реестр первичных источников в `docs/psychometrics-sources.md`.

**НЕ ДЕЛАЙ В ЭТОМ ШАГЕ.** Не включай в production методику без разрешения. Не создавай русские версии там, где перевод не валидирован.

**ТЕСТЫ.** Для каждой методики: ожидаемое число вопросов, порядок и коды, допустимые ответы, обратные пункты, пропуски, контрольный результат на фиксированном наборе ответов, соответствие официальному ключу, снимок версии, срабатывание шлюза прав, невозможность смешать локали, невозможность изменить вопрос без новой версии.

**ГОТОВО, КОГДА.** Ключи подтверждены контрольными тестами, а в production доступны только разрешённые версии.
