# Шаг 53. Карта жизни, программы и обзоры

- **Приоритет:** P9
- **Зависит от:** шаг 52
- **Feature flag:** EVA_LIFE_MAP`, `EVA_LIFE_PROGRAMS`, `EVA_LIFE_REPORTS
- **Объём:** 2 PR
- **Ветка:** `step/53-map-programs-reports`

> Перед началом прочитай `CLAUDE.md` — там протокол автономной работы.
> Выполни только этот шаг: проверки, `PROGRESS.md`, pull request, мерж по условиям
> из протокола. Затем возьми следующий шаг порции. На отметке ⏸ остановись.

---

**ЦЕЛЬ.** Дать взгляд на жизнь целиком и структурированные короткие программы.

**СДЕЛАЙ.**
1. Создай `life_domains`, `life_domain_assessments`. Сферы: здоровье и энергия, отношения, семья, работа, финансы, развитие, отдых, среда, смысл. Для каждой — удовлетворённость и важность по шкале 1–10, желаемое изменение, допустимая цена изменения, комментарий. Высокая важность при низкой удовлетворённости — кандидат на внимание; низкая важность при низкой удовлетворённости проблемой автоматически не считается.
2. Создай `life_programs`, `life_program_enrollments`, `life_program_sessions`. Направления: снижение перегрузки, понимание себя, уверенное общение, личные границы, прокрастинация, принятие решений, новый этап жизни, рабочий ритм, отношение к деньгам, поддерживающие привычки. Длительность 7, 14 или 30 дней. Каждый день: короткое объяснение, один вопрос, одно упражнение, одно действие, фиксация результата. Доступны продолжение, повтор дня, минимальная версия, пауза и смена программы.
3. Создай `life_reports`. Формируй итог дня, недели и месяца; итог года — только по запросу или согласию. Отчёты строятся из детерминированных агрегатов и подтверждённых событий; LLM не придумывает отсутствующие факты и только формулирует готовые данные.
4. Отчёты формируются заданиями существующей очереди `analytics`, отдельный планировщик не создаётся.

**НЕ ДЕЛАЙ В ЭТОМ ШАГЕ.** Не считай корреляции — шаг 54. Не создавай вторую систему целей: цели остаются в «ВЕКТОР».

**ТЕСТЫ.** Программа продолжается после перерыва; минимальная версия дня засчитывается; отчёт при нехватке данных честно сообщает об этом; повторный запуск формирования отчёта не создаёт дубль.

**ГОТОВО, КОГДА.** Пользователь видит карту сфер, может пройти программу и получает честные периодические итоги.
