# Шаг 55. Психологические практики

- **Приоритет:** P10
- **Зависит от:** шаги 50, 52
- **Feature flag:** EVA_PRACTICES
- **Объём:** 2 PR
- **Ветка:** `step/55-practices`

> Перед началом прочитай `CLAUDE.md` — там протокол автономной работы.
> Выполни только этот шаг: проверки, `PROGRESS.md`, pull request, мерж по условиям
> из протокола. Затем возьми следующий шаг порции. На отметке ⏸ остановись.

---

**ЦЕЛЬ.** Дать низкоинтенсивные образовательные и навыковые модули, не называя их психотерапией.

**СДЕЛАЙ.**
1. Создай `practice_sessions`, `practice_entries`.
2. Реализуй модули: разбор мысли (ситуация, автоматическая мысль, эмоция и её интенсивность, телесная реакция, действие или избегание, доказательства за и против, более сбалансированная мысль, небольшой поведенческий эксперимент, фактический результат); поведенческая активация; решение проблем; навыки принятия и действия по ценностям; эмоциональная регуляция и навыки отношений; самосострадание.
3. Структура сессии: короткий check-in → выбор цели (выговориться, разобраться, найти шаг, практика) → один вопрос за раз → краткая гипотеза → одна практика → один следующий шаг → оценка полезности → согласованный follow-up.
4. Практика может создать задачу или заметку только с подтверждения пользователя.
5. Каждая практика имеет минимальную версию для дней с низкой энергией.

**НЕ ДЕЛАЙ В ЭТОМ ШАГЕ.** Не называй практики терапией. Не обещай результат. Не создавай задачи автоматически.

**ТЕСТЫ.** Практика прерывается и продолжается; результат сохраняется без ИИ; кризисный сигнал прерывает практику и передаёт управление кризисному протоколу; текст не содержит медицинских обещаний.

**ГОТОВО, КОГДА.** Пользователь может пройти короткую практику и получить один конкретный следующий шаг.
