# Шаг 56. Антистресс-мини-приложения

- **Приоритет:** P10
- **Зависит от:** шаги 26, 55
- **Feature flag:** EVA_ANTISTRESS
- **Размер:** S

> Протокол — `CLAUDE.md`. Шаг выполняется внутри batch: pull request, CI и ревью — на batch, не на шаг.

---

**ЦЕЛЬ.** Дать быстрые практики, работающие без модели и без сохранения текста.

**СДЕЛАЙ.**
1. Реализуй: дыхание, заземление 5-4-3-2-1, счёт, спокойная визуальная концентрация, прогрессивное расслабление, сортировка мыслей, одна минута фокуса, выгрузка беспокоящих мыслей, короткая прогулка, сканирование тела.
2. Без обращения к модели, если анализ текста не требуется. Без обязательного сохранения текста. Остановка в любой момент.
3. Уважать уменьшенную анимацию, не использовать мерцание и резкие звуки.
4. Отметка состояния до и после — по желанию.
5. Открываются внутри WebApp и по подписанной ссылке из Telegram. Ссылка содержит короткоживущий подписанный токен без открытого идентификатора пользователя.
6. Практики не заменяют кризисный протокол, не обещают устранить тревогу и не используют награды для формирования зависимости.

**НЕ ДЕЛАЙ В ЭТОМ ШАГЕ.** Не подключай LLM без необходимости. Не собирай текст без явного согласия.

**ТЕСТЫ.** Практика работает без сети после загрузки; уменьшенная анимация; ссылка с истёкшим токеном не открывается; чужой токен не даёт доступа; текст не сохраняется по умолчанию.

**ГОТОВО, КОГДА.** Практику можно открыть из Telegram за одно нажатие и пройти без единого обращения к модели.
