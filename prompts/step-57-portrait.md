# Шаг 57. Живой портрет Евы

- **Приоритет:** P10
- **Зависит от:** шаги 26, 41
- **Feature flag:** EVA_PORTRAIT
- **Объём:** 2 PR
- **Ветка:** `step/57-portrait`

> Перед началом прочитай `CLAUDE.md` — там протокол автономной работы.
> Выполни только этот шаг: проверки, `PROGRESS.md`, pull request, мерж по условиям
> из протокола. Затем возьми следующий шаг порции. На отметке ⏸ остановись.

---

**ЦЕЛЬ.** Дать присутствие Евы в интерфейсе, не мешая работе.

**СДЕЛАЙ.**
1. Создай `portrait_settings`. Плавающий круглый портрет 64×64 px, 56×56 px на маленьком экране, справа или слева, выше нижней навигации, сворачивается и полностью отключается.
2. Состояния: покой, внимание, слушает, думает, говорит, успех, поддержка, ошибка.
3. Анимации: редкое моргание, минимальное дыхание, небольшое движение взгляда, мягкая мимика, движение рта по уровню аудио синтеза. Уважать уменьшенную анимацию.
4. Панель действий: написать Еве, надиктовать сообщение, обсудить экран, создать заметку, создать задачу.
5. Контекст экрана передаётся структурированно: модуль, экран, тип и идентификатор сущности, выбранный раздел. DOM и HTML не передаются. Backend проверяет владение и сам получает краткие данные.
6. В MVP не использовать Live2D, 3D, непрерывный микрофон, дуплексное аудио и распознавание эмоций по лицу или голосу.
7. Запрещены сексуализированное поведение, ревность, обида, формулировки привязанности вроде «я скучала», уровни отношений, автоматическое включение микрофона и навязчивые подсказки.
8. В кризисном режиме портрет спокойный и серьёзный, без улыбки.

**НЕ ДЕЛАЙ В ЭТОМ ШАГЕ.** Не включай портрет во время прохождения теста. Не передавай содержимое экрана в модель напрямую.

**ТЕСТЫ.** Портрет не перекрывает элементы действий на малом экране; отключается полностью; уменьшенная анимация; нагрузка на процессор в пределах бюджета; контекст чужой сущности отклоняется.

**ГОТОВО, КОГДА.** Портрет помогает начать разговор о текущем экране и не мешает ни на одном разрешении.
