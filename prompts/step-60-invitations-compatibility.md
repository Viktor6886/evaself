# Шаг 60. Приглашения, согласия, отчёт совместимости и реферальная атрибуция

- **Приоритет:** P11
- **Зависит от:** шаги 47, 59
- **Feature flag:** EVA_INVITATIONS`, `EVA_COMPATIBILITY
- **Объём:** 2–3 PR
- **Ветка:** `step/60-invitations-compatibility`

> Перед началом прочитай `CLAUDE.md` — там протокол автономной работы.
> Выполни только этот шаг: проверки, `PROGRESS.md`, pull request, мерж по условиям
> из протокола. Затем возьми следующий шаг порции. На отметке ⏸ остановись.

---

**ЦЕЛЬ.** Дать совместные тесты и парный отчёт без скрытого анализа человека.

**СНАЧАЛА ПРОВЕРЬ.** Существующее назначение conversation `partner_analysis` и таблицу `referrals`. Реферальная механика расширяется, а не создаётся заново.

**СДЕЛАЙ.**
1. Создай `invitations`, `invitation_consents`, `partner_questionnaire_answers`, `compatibility_reports`.
2. Приглашение содержит токен, тип, срок, пригласившего. Ссылка отзывается; просроченная ссылка анкету не открывает.
3. Приглашённый видит цель, состав собираемых данных и правила конфиденциальности. Отдельное согласие обязательно: без него ответы не сохраняются и отчёт не создаётся.
4. Состав анкеты версионируется как артефакт реестра шага 13. Темы: ценности, планы, конфликт, коммуникация, близость и автономия, деньги и быт, границы, поддержка; при необходимости — базовые черты личности через разрешённую методику.
5. Сырые ответы участников закрыты друг от друга. Оба участника отдельно подтверждают доступ к общему отчёту. Чувствительные ответы раскрываются только при явном согласии на обмен. Партнёр может удалить свои данные и отозвать доступ.
6. Отчёт формируется детерминированным движком правил: общие ценности, различия, коммуникация, конфликт, близость и автономия, быт и деньги, цели, границы, поддержка, сильные стороны, риски, вопросы для разговора. LLM только объясняет готовые сигналы.
7. Один процент не является главным выводом. Каждый вывод связан с ответами обоих и помечен уровнем уверенности. Диагнозы, вердикт «подходит или не подходит» и предсказание судьбы отношений запрещены. Отчёт прямо сообщает, что не заменяет работу специалиста.
8. Ссылки для друзей: одноразовые или ограниченные по сроку, друг проходит разрешённый тест, владелец получает только заранее описанный результат. Сырые ответы без согласия не раскрываются.
9. Реферальная атрибуция, скидка и партнёрский анализ — разные сущности. Токен приглашения не создаёт награду без активного правила кампании. Защити от самореферала, повторного использования и циклических приглашений. Сохраняй источник регистрации и конверсию до оплаты.

**НЕ ДЕЛАЙ В ЭТОМ ШАГЕ.** Не создавай отчёт до завершения обоими участниками. Не раскрывай сырые ответы. Не включай методику без прав.

**ТЕСТЫ.** Просроченная и отозванная ссылка не открывают анкету; отсутствие согласия не сохраняет ответы; отчёт недоступен до подтверждения обоими; сырые ответы партнёра недоступны; самореферал отклоняется; удаление данных партнёром убирает его вклад из отчёта.

**ГОТОВО, КОГДА.** Парный отчёт строится только на явных согласиях и не содержит вердиктов.
