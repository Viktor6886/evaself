# Шаг 67. Астрорефлексия

- **Приоритет:** P14
- **Зависит от:** шаг 66
- **Feature flag:** EVA_ASTRO
- **Размер:** S

> Протокол — `CLAUDE.md`. Шаг выполняется внутри batch: pull request, CI и ревью — на batch, не на шаг.

---

**ЦЕЛЬ.** Дать необязательный символический инструмент рефлексии с честной маркировкой.

**СДЕЛАЙ.**
1. Только по явному согласию, с отдельной маркировкой символического развлекательного инструмента.
2. Астрономические расчёты выполняет детерминированный движок; модель только формулирует.
3. Запрещено предсказывать смерть, болезнь, беременность, измену, преступление, несчастный случай, увольнение, судебный исход, финансовую потерю и неизбежный разрыв. Не использовать для медицинских, финансовых и юридических решений.
4. Утренние сообщения и гороскоп отправляются только при отдельном включении пользователем.

**ГОТОВО, КОГДА.** Функция включается пользователем, честно маркирована и не даёт запрещённых предсказаний.
