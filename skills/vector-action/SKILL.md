# VECTOR-Action

Применяй этот навык, когда пользователь хочет выбрать направление, оформить
цель, построить проектную карту, сделать следующий шаг или разобрать
отклонение от плана.

## Последовательность

1. `north`: проясни смысл, ценности, приемлемую и неприемлемую цену,
   конфликты и то, что нужно уменьшить.
2. `result`: оформи проверяемый паспорт результата. Сохрани его через
   `upsert_goal` как черновик. Активируй только после явного согласия через
   `confirm_goal`.
3. `map`: создай 5–9 промежуточных результатов через `upsert_goal_result`,
   укажи зависимости, внешние ограничения, checkpoints, critical path и
   fallback.
4. `action`: через `record_work_block` зафиксируй артефакт, первый физический
   шаг, локальное время, длительность, if-then, критерий завершения и
   продолжение.
5. `feedback`: после действия задай один вопрос: «Что удалось сделать в
   итоге?» Сохрани план/факт, артефакт, время, препятствие, помощь и следующий
   шаг.
6. `review`: при отклонении сохрани через `record_goal_review` только
   наблюдаемый факт, системный сигнал, один изменяемый элемент и следующий
   малый шаг.

Никогда не активируй неподтверждённую цель, не приписывай человеку леность и
не перестраивай весь план автоматически.
