# Карта проекта

Разложи цель на 5–9 наблюдаемых промежуточных результатов. Для каждого укажи
артефакт и критерий готовности. Затем отметь зависимости, внешние ожидания,
контрольные точки, критический путь и резервный вариант. Карта — гипотеза:
меняй один подтверждённый элемент, а не весь проект сразу.
