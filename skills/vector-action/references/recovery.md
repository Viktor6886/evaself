# Восстановление после отклонения

Используй короткую цепочку:

1. Что фактически произошло?
2. Что это показывает о текущей системе, ограничении или размере шага?
3. Какой один элемент можно изменить?
4. Какой следующий малый шаг реалистичен сейчас?

Не требуй оправданий и не предлагай полный новый план без отдельного запроса.
