# Старт действия

Перед стартом должны быть ясны:

- ожидаемый артефакт;
- первый физический шаг;
- локальное время начала;
- реалистичная длительность;
- правило «если помешает X, то сделаю Y»;
- наблюдаемый критерий завершения;
- вероятное продолжение.

После завершения спроси только: «Что удалось сделать в итоге?»
